# Aviation Analytics: Arrival Delays and Flight Cancellations

**Author: Pavel Šorohhov**

An analysis of **539,747 flight records from January 2025**, using the US Bureau of Transportation Statistics (BTS) reporting-carrier dataset. The project combines arrival-delay analysis in **R** with an investigation of cancellations in **DuckDB SQL**, using DBeaver.

## Report

- [Read the PDF report](AviationReport_PavelSh.pdf)
- [Download the HTML report](AviationReport_PavelSh.html) and open it in a browser to expand the original code blocks.

The standalone `.R` and `.sql` files contain the original analysis scripts. The Quarto report retains the original R and SQL commands and includes three figures generated by the original R code.

## Research questions

1. How do arrival delays vary during the month and across reporting airlines?
2. Does the difference between United Airlines (UA) and Southwest Airlines (WN) persist when comparing shared directional routes?
3. How concentrated are OH cancellations in particular days and origin airports, and which cancellation reasons were reported?

## Main findings

### Monthly overview

| Measure | Result |
| --- | ---: |
| Flight records | 539,747 |
| Cancelled flights | 16,312 (3.02%) |
| Diverted flights | 1,166 |
| Eligible arrivals | 522,269 |
| Eligible arrivals delayed by 15+ minutes | 18.79% |
| Mean signed arrival delay | 3.76 minutes |
| Median signed arrival delay | -8 minutes |

The negative median indicates that early arrivals were common. Long positive delays pull the mean upward. These statistics include early arrivals; the mean is not restricted to delayed flights.

### Comparing UA and WN

Across all their routes, UA's arrival-delay rate was approximately **2.42 percentage points higher** than WN's. On **139 shared directional routes**, with at least 30 eligible arrivals per airline and equal weight for each route, UA's mean route delay rate was approximately **0.15 percentage points lower**.

The average UA-minus-WN gap remained negative at the 30-, 60-, and 100-flight thresholds. Both route selection and weighting change between the aggregate and shared-route comparisons, so the result does not isolate an airline effect.

### OH cancellations

OH had the highest cancellation rate in the airline comparison, at **9.00%**. January 6, 10, and 30 accounted for **42.71% of its monthly cancellations**, but **10.16% of its scheduled flights**.

On these dates, DCA and CLT had the largest numbers of cancelled OH departures. Weather was the dominant reported cancellation category on January 6 and 10; Carrier was dominant on January 30. These categories do not identify the specific events behind each cancellation.

## Data and definitions

**Source:** BTS, *Reporting Carrier On-Time Performance*, January 2025.

[Download the original January 2025 ZIP archive](https://www.transtats.bts.gov/PREZIP/On_Time_Reporting_Carrier_On_Time_Performance_1987_present_2025_1.zip).

Extract the archive and keep the original CSV filename. Create a `data` folder in the main project folder and place the CSV at this relative path:

```text
data/On_Time_Reporting_Carrier_On_Time_Performance_(1987_present)_2025_1.csv
```

The raw CSV is downloaded separately because it exceeds GitHub's [100 MiB limit for ordinary Git files](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github). The analysis uses the complete monthly file, with no sampling.

- **Cancellation rate:** cancelled flight records divided by all flight records in the selected group.
- **Eligible arrivals:** flights with `Cancelled == 0`, `Diverted == 0`, and a known `ArrDelay`.
- **Arrival-delay rate:** the percentage of eligible arrivals with `ArrDelay >= 15`.
- **Signed arrival delay:** negative values indicate early arrivals; positive values indicate late arrivals.
- **Directional route:** a specific origin-destination pair. The reverse direction is a different route.

Arrival-delay rates exclude cancellations and diversions. They should be considered alongside cancellation rates, rather than treated as a complete measure of reliability.

## Reproduce the analysis

### R

1. Download the repository files into one project folder and add the CSV under `data` as described above.
2. Open the saved `.R` script in RStudio. Use the main project folder as the working directory so the relative data path resolves correctly.
3. Install the packages using the installation lines already present in the original script, then run the script from the beginning.

The script uses `tidyverse`. It also loads `gapminder`, which is retained from the original setup but is not used for the aviation calculations.

### SQL in DBeaver

1. Open a DuckDB connection in DBeaver and open the saved `.sql` script.
2. In the original import statement, set the CSV path to the file's location on your computer.
3. Run the import once in a database without an existing `flights` table, then run the analysis queries in order. If that table has already been imported, start with the queries after the import statement.

The SQL uses DuckDB's `read_csv` function; DBeaver is the interface used to run the queries.

### Quarto

Keep `AviationReport_PavelSh.qmd` in the main project folder, alongside the scripts and the `data` folder. With the packages installed, open it in RStudio and use **Render** to generate HTML. See the [Quarto guide for RStudio](https://quarto.org/docs/tools/rstudio.html).

The executing R chunks and three figures recalculate during rendering. Package installation and `View()` commands are retained but disabled during rendering. SQL is run separately in DBeaver.

The formatted airline and route tables, SQL tables, and written interpretations are stored January 2025 results. They do **not** update automatically if a different dataset is substituted. The supplied PDF is a reading copy of the report; HTML can also be printed to PDF from a browser.

## Limitations

This is a descriptive analysis of one month. It does not control for departure times, weather exposure, aircraft, or other operating conditions. Shared-route comparisons do not establish causality or statistical significance. OH's three peak dates were selected after inspecting the daily cancellation rates.
